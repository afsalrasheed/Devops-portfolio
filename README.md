# AFSAL A R — Animated DevOps Portfolio

A responsive portfolio built with HTML, CSS, JavaScript, Three.js and GSAP ScrollTrigger.

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Start a local server (recommended: VS Code Live Server).
4. Open the local URL in a modern browser.

Three.js and GSAP are loaded from jsDelivr CDN, and Google Fonts are loaded online. An internet connection is needed for the 3D and scroll animations and custom fonts; the portfolio content remains visible if those services are unavailable.

## Files
- `index.html` — page structure and portfolio content
- `assets/img_8935.webp` — optimized hero portrait
- `assets/afsal-profile.png` — supplied profile portrait
- `css/style.css` — visual design and responsive layout
- `js/main.js` — Three.js electric-blue DNA scene, GSAP scroll animation and interactions

## Customise
- Update the contact details and links in `index.html` if needed.
- Replace project repository links with the exact repositories you want to showcase.
- Change colours in the `:root` variables in `css/style.css`.
- Adjust the 3D model, lighting and scroll animation in `js/main.js`.

The electric-blue 3D DNA helix is generated procedurally in Three.js; no external 3D model file is required.
